- (decision) Paradigm [ADOPTED by Phill 2026-11-03]: ports and adapters with a single-STA actor. MCP tools -> use cases -> IOneNoteGateway port; ComGateway (one STA thread, queue, timeouts, reconnect, idle release) is the only code that touches COM; pure XML model has no COM. - (decision) Page content contract [Phill 2026-11-03]: raw OneNote 2013 XML in both directions; no markdown/intermediate format. Binds every read/write tool to one representation; prevents per-tool formats and lossy round-trips.
- (direction) Phill 2026-11-03: wrap the MCP in a Claude Code skill; part of its job is prompting the user to allow notebooks not yet allowed.
- (decision) Access model [Phill 2026-11-03]: every notebook is readable; writes need a per-notebook grant. The server enforces the allowlist (not the skill). Prevents a skill-only or model-grantable gate.
- (decision) Write safety [Phill 2026-11-03]: before every page write the server validates the XML against the 2013 schema and checks every objectID it references exists on the page as read just before (read-compare-write). Prevents silent overwrite via a wrong objectID under UpdatePageContent's partial-update semantics.
- (decision) Read default [Phill 2026-11-03]: page reads exclude binary content unless the caller asks. Prevents multi-MB base64 responses by default.

- (decision) Grants [Phill 2026-11-03]: one grant per notebook, persistent until revoked, stored in a config file under %APPDATA% that the skill can show. Permanent delete needs a separate second grant per notebook.
- (decision) Tool shape [Phill 2026-11-03]: thin, roughly one MCP tool per COM method, raw XML in and out. Server-added behaviour only for the access check, search post-filtering, and one uniform error shape mapping HRESULTs to actionable errors. - (decision) Task-shaped tools [Phill 2026-11-03]: allowed later as a layer on top: recipes in the skill first; promoted to a server use case when common or needing atomicity. They compose thin use cases through the same gateway and access check; never bypass them.
