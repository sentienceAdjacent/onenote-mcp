- (constraint by spike-1) COM must be bound early (vtable: interop or ComImport). IDispatch late binding fails for 64-bit clients on M365 16.0.20527 (typelib registered Win32-only; pwsh7 E_FAIL, pywin32 TYPE_E_LIBNOTREGISTERED). [spike-1 findings 2026-11-03]
- (constraint by spike-1) dateExpectedLastModified is an exact UTC match against page lastModifiedTime, which does not advance for COM edits to pages not displayed in OneNote; stale writes/deletes then succeed. Concurrency guard must add content read-compare-write and be documented as best-effort. [spike-1 findings 2026-11-03]
- (constraint by spike-1) Pass dateExpectedLastModified as a UTC DateTime parsed from the XML attribute; local-kind values are rejected (0x80042010). [spike-1 findings 2026-11-03]
- (constraint by spike-1) FindPages indexed-only missed a fresh page for >300 s in 2 of 3 runs; fIncludeUnindexedPages=true returns all unindexed pages unfiltered. Search needs post-filtering/fallback scan and must be reported as possibly incomplete. [spike-1 findings 2026-11-03]
- (constraint by spike-1) Cloud-notebook images may have no local binary: GetBinaryPageContent 0x8004200f and piBinaryData drops the Image. Reads must degrade to 'binary unavailable', not fail. [spike-1 findings 2026-11-03]
- (constraint by spike-1) Soft-deleted pages reappear in the recycle bin under a new ID (sections keep theirs); restore cannot rely on the old page ID. [spike-1 findings 2026-11-03]
- (constraint by spike-1) Single STA COM thread serialises all tool calls (verified 8 parallel calls in C# and Python hosts); it needs per-call timeouts, retry on RPC_E_CALL_REJECTED/RETRYLATER (observed), and awareness that slow calls (docx Publish 2.9 s) block others. [spike-1 findings 2026-11-03]
- (constraint by spike-1) Stack: C# (ModelContextProtocol 2.3.1, .NET 10, GAC OneNote 15 interop) recommended over Python (mcp 2.3.0 + comtypes; pywin32 unusable). Interop is not embeddable: ship it or hand-declare ComImport IApplication. Pending Phill's acceptance. [spike-1 findings 2026-11-03]
- (constraint by spike-1) NavigateTo changes the user's visible page and thereby changes lastModifiedTime behaviour; treat it as a user-visible side effect, not a free read. [spike-1 findings 2026-11-03]
