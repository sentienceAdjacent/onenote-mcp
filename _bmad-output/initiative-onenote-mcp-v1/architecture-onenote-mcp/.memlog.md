- (decision) Paradigm [ADOPTED by Phill 2026-11-03]: ports and adapters with a single-STA actor. MCP tools -> use cases -> IOneNoteGateway port; ComGateway (one STA thread, queue, timeouts, reconnect, idle release) is the only code that touches COM; pure XML model has no COM. - (decision) Page content contract [Phill 2026-11-03]: raw OneNote 2013 XML in both directions; no markdown/intermediate format. Binds every read/write tool to one representation; prevents per-tool formats and lossy round-trips.

- (decision) Access model [Phill 2026-11-03]: every notebook is readable; writes need a per-notebook grant. The server enforces the allowlist (not the skill). - (decision) Write safety [Phill 2026-11-03]: before every page write the server validates the XML against the 2013 schema and checks every objectID it references exists on the page as read just before (read-compare-write). - (decision) Read default [Phill 2026-11-03]: page reads exclude binary content unless the caller asks. Prevents multi-MB base64 responses by default.
