## Q1. Path stability: how far to go

The spine's Deferred row (`architecture-onenote-mcp.md:582-583`) asks for notebook and section `path` after a close and reopen, a rename in OneNote, and a rename of the folder (local) or the OneDrive item (cloud). Grants key on `NotebookKey` (AD-6), which rests on `path` being stable.

:::question
**Q1: which path changes should 2.2 probe?**
- (a) All of them: close and reopen, rename in OneNote, and rename the local folder and the OneDrive item. Renaming the OneDrive item may break MCP Test Cloud's sync, so it runs last and you may need to reopen the notebook afterwards.
- (b) Close and reopen plus a rename in OneNote only. Folder and OneDrive renames stay in the spine's Deferred row.

Recommended: (a)
:::

:::
