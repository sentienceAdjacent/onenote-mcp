# 5.1 live runs: run sheet (v2, after run 1's hang)

Four runs, about 1.5–2 hours in all. I start each run and send each step as an action card in the 5.1 Inbox thread; you press **Done**, or **Can't do it** with a note. A step waits up to 30 minutes.

**What changed since run 1:**
- Run 1 froze OneNote: the probe created a new section next to a page you had on screen, and OneNote's "syncing changes" dialog blocked its window. The delete that came after it took 0.1 s.
- Now the probe makes sure nothing in its area is on screen before it creates, renames, moves, deletes or publishes there. If something is, it first asks you to click a safe page:
  - MCP Test > Seed (its first page);
  - MCP Test Cloud > Probes > Text Page in the cloud runs.
- Every call is limited to 60 seconds. If one blocks, the run stops cleanly: it records which step blocked and asks you to press Cancel on any dialog. It never starts a second OneNote.

**Before each run:** OneNote desktop is running (not as administrator), with MCP Test and MCP Test Cloud open. Click MCP Test > Seed. Run 1's leftover "probe run 1111-033107" group is harmless, but keep it off screen.

**Steps that can come at any time:**
- **Show elsewhere:** click the safe page above, without typing.
- **A call blocked:** if a "syncing changes" (or any) dialog is open, press Cancel, check that OneNote responds, and tell me which dialog it was. Don't close OneNote. The run then ends.

Everything the probes create sits in a "probe run <stamp>" group inside the two test notebooks, or in throwaway notebooks. The guard refuses anything else before calling OneNote.

## 3. Protected-section deletes (about 35–45 min, all in OneNote; local pass, then cloud pass)

Use one password for the whole sitting. "Safe" is the safe page for that pass.

1. Password-protect "probe vault <stamp>" (right-click its tab > Password Protect This Section) and leave it unlocked.
2. Lock it with Ctrl+Alt+L.
3. Click Safe (expected).
4. (Local only) Click the locked section, then "click here to unlock", and leave the empty password dialog open.
5. (Local only) Cancel the password dialog.
6. Unlock the section, then click Safe. Tell me if it locks again when you leave it.
7. Press Ctrl+Alt+L again. This also locks the deleted copy in the recycle bin.
8. Open History > Notebook Recycle Bin, open the deleted "probe vault <stamp>" and unlock it (don't restore it), then click Safe. Tell me if it locks again.
9. (Only if the backup opens locked) Unlock the backup copy.
10. Close the backup copy of "probe vault <stamp>". Don't delete it.

The cloud pass repeats steps 1–3 and 6–10 on MCP Test Cloud.

## 4. Notebook deletes (about 15–25 min: OneNote, then a browser)

1. (If it opened) Close the backup copy "MCP Test Throwaway <stamp> b".
2. (Skipped if you made it beforehand) Create the OneDrive notebook "MCP Test Throwaway Cloud" (File > New > OneDrive > Documents), with a section "probe" holding a page "probe page" with a word on it, and wait for it to sync.
3. (Only if the soft delete closed it) Reopen "MCP Test Throwaway Cloud" from File > Open > OneDrive > Documents. If it's gone, say so; don't restore it.
4. Close its backup copy.
5. In a browser, check OneDrive > Documents and its recycle bin: is "MCP Test Throwaway Cloud" still there, in the recycle bin, or gone? Don't restore it.
